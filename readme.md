## 这是什么

一个运行在 Spotify 内的歌词模块，**基于 [Spicy EX](https://github.com/amarinne/spicy-ex)**（作者
[amarinne](https://github.com/amarinne)）修改而来，主要面向中文用户。

**本仓库是修改版，不是原项目。** 上游的版权归原作者所有，本仓库的修改部分同样以
**AGPL-3.0** 发布 —— 详见 [LICENSE](LICENSE) 与 [NOTICE](NOTICE)。

## 相对上游做了什么

### 完整简体中文
- 新增 `values-zh-rCN`，覆盖全部 751 条字符串资源
- 修复上游 9 条「Java 引用了但资源里不存在」导致中文界面回退英文的问题
- 界面语言选择器：修复某些设备上语言列表只剩当前语言、切过去就切不回来的问题

### 按名称搜索歌词
上游只能自动匹配，标题写法不一样就搜不到（比如 Spotify 报
「反乌托邦 - 拼接版」，而网易云上叫「拼接乌托邦」）。

现在可以：**选平台 → 输入歌名 → 看它返回的全部结果（歌名 + 作者）→ 自己点选**，
跳过自动匹配与 AI 判断，按 ID 直接取词。

### 搜索与选源
- 首次搜索时**简体写法优先**，避免命中繁体版本
- 标题里的 `·`、`–`、`—` 等分隔符统一，修复「一个字之差就当成两首歌」
- 简繁折叠：`從奇蹟中誕生` 与 `从奇迹中诞生` 视为同一首
- 选源排序：**自带翻译/转写的来源**优先于源枚举顺序
- 网易云、QQ 音乐空结果自动重试（接口限流时返回空列表）

### 数据备份
- **导出 / 导入设置与数据**，使用安卓原生文件选择器
- 适用于清理应用数据、换机、或在两个模块版本之间迁移

## 安装

1. 安装 APK
2. 在 **LSPosed** 中启用本模块，**作用域勾选 Spotify**
3. **强制停止 Spotify**，再打开

> **注意**：本版使用**自己的签名与包名**（`com.spotifyplusplus`），
> **无法覆盖安装上游的 `com.eza.spicyex`**。切换时请先卸载旧的，
> 设置保存在 Spotify 自己的目录里，不会因此丢失。
