# Spotify++ 1.6.4

本版是从 1.5 以来的一整轮更新：合并上游 v2.1.0 + v2.1.4，恢复三组被合并丢掉的设置入口，恢复 Apple Music 歌词来源，并重做歌词界面的动效与文字排版。

下面是完整的更新日志，按版本顺序排列。1.6.0～1.6.3 都发过测试版，内容是累加的，**1.6.4 已包含它们全部**。

---

## 1.6.4（正式版）

- **逐行歌词不再假装逐字**：来源显示「逐行」的歌词（Apple Music · 逐行、LRCLIB · 逐行、网易云 · 逐行、Spotify · 逐行等）本身没有每个字的时间戳，以前会按整行时长估出一条"逐个字点亮"的进度，看起来像逐字其实是假的。现在这类歌词**按整行处理**。
- **逐字歌词保持 1.6.3 的修复**：带真实逐字时间的行继续按每个字自己的起止时间推进，白条贴着正在唱的字走。
- Android Auto 投射页保持原样（它本来就是按页切片做平滑扫光）。

## 1.6.3（BETA）

- **逐字歌词不再「整句一起变大」**：以前逐字行被套上整行缩放，看起来是整句一起放大；现在逐字行不套整行缩放，交给逐字上浮和按住字放大来表现。
- **白条（卡拉OK推进）跟上唱到的字**：以前逐字行的白条被整行进度覆盖，总是慢半拍；现在按逐字进度推进。
- 整行歌词与 Android Auto 投射页行为不变（加了测试钉住）。

## 1.6.2（BETA）

- **翻译行排版**：字号默认从 70% 降到 62%，新增「翻译字号」设置（40%–100%）；翻译字重**跟随主歌词**；主歌词高亮时**翻译保持灰色**（与 Apple Music 一致）。
- **背景变暗**：亮度曲线改回线性，并加门限——「背景变暗」低于 15 时不再套用那层固定的 0.38 强暗化，**最浅档真正变亮**。
- **顶部模糊参数回到原版**：新增的「背景模糊」默认改为 100%（此值等于上游原始参数），想要更重可自己拉到 200%。
- **Apple 动效补了两处帧驱动**（切歌入场、载入入场时请求帧）。

## 1.6.1（BETA）

- **删除「Spicy 手动令牌」**：能填、能存、能备份，但读它的分支被恒定 false 挡死，且它服务的旧传输通道已废弃——死开关，移除。**「SpicyLyrics.org 客户端密钥」不受影响**。
- **导出 / 导入补上图标**（保存 / 还原），和其他行统一。
- **新增「清除本模块的所有内容」**（设置 → 关于与诊断）：一次清掉本模块自己写的所有数据——歌词目录库、响应缓存、AI 付费账本、设置、加密保存的各类密钥、字体与语言包、诊断草稿、agent 通道等。只清本模块的，**不动 Spotify 自己的数据与已导出的备份**，清完需重启 Spotify。
- **恢复 Apple Music 作为歌词来源**：来源面板第二位（SpicyLyrics.org → Apple Music → Spotify → AMLL → LRCLIB → QQ → 网易云）、默认启用、参与自动竞选与评分。代码与上游一致。
- **修好顶部模糊**：把「歌曲信息背景」设成模糊时，以前遮罩被隐藏、模糊却没启动，导致歌词清晰压在专辑封面和歌名上；现在补上漏掉的调用，歌词经过头部会在模糊带里虚化。
- **新增「背景模糊」设置**（布局编辑器 → 背景，50%–200%），并把「背景变暗」的档位曲线改成真正可用。

## 1.6.0（BETA）

- **合并上游 v2.1.0 + v2.1.4**：378 个文件变更（+40187 / −4950），27 个冲突文件全部手工解决。
- **恢复三组被合并丢掉的面板入口**（底层类都在，但没有任何调用点，编译和测试全绿也发现不了）：
  - 导出 / 导入设置与数据（现为面板独立「备份」分组）
  - 自定义字体路径编辑（布局编辑器 → 字体）
  - SpicyLyrics.org 客户端密钥的「显示」
  - 并补了 3 条测试，专门钉住"注册了但没有渲染器"这类丢失
- **来源面板两处显示修复**：探测不再依赖会话里的「当前曲目」（否则整列显示「点击检查」）；已找到的来源不再显示成没查过（改为「已找到 · 点击重试」）。
- 版本号 1.6.0 / versionCode 12。

## 升级说明

- **从 1.5、1.6.x 任意版本直接覆盖安装即可**，签名相同，不需要卸载。
- **从 1.3.1 或更早升级必须先卸载**：那把签名密钥已经丢失，新包签名不同，系统不允许覆盖。
- 「逐行」还是「逐字」由歌词来源决定，来源面板每行都会标出（例如「AMLL · 逐字」「QQ 音乐 · 逐字」「Apple Music · 逐行」）。想要逐字跳动和白条跟随，请选标着「逐字」的来源。
- **仿 Apple Music 的上浮需要把「动画样式」选成 Apple Music**（默认是渐变扫过，官方默认也一样）。

## 已知限制

- 来源没有逐字时间轴时无法逐字跳动，这是数据本身的限制，不是渲染问题。
- Apple Music 的公开接口已被证实可用（能取到歌词），但它随时可能变更或限流。
- 桥接的存在性探测中「未安装」分支只有单元测试覆盖；真机需要安装 HyperGlow 配套应用才能验证。
- 日语、韩语、俄语 README 的本地化仍有历史缺口。

## 如果你升级后遇到异常

先按影响从小到大清一次本地存储：设置 → 歌词来源 →「清除已保存的歌词」→ 系统设置 → Spotify → 清除缓存 → 清除存储（会退出登录）；或者直接用 设置 → 关于与诊断 →「清除本模块的所有内容」。
