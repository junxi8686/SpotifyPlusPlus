# Spotify++ 1.6.0

本版在 v1.5 的基础上移植了上游 v2.1.0 与 v2.1.4 两个版本的内容，并保留本仓自己的排序、评分与推送策略。

## 新增

- 纸艺着色器背景：纸粒、网格渐变、Kawarp、Voronoi、Perlin 噪声，可单独调参，并跟随封面取色
- 逐字 / 逐词时间轴的字间填充与渐变更平滑
- 语言偏好（优先原文 / 优先中文翻译）
- 手动令牌歌词来源
- Android Auto 显示改进
- 日语注音新增 eza 式拼音 / 粤拼输出
- 悬浮窗与沉浸式界面若干显示修复

## 修复

- 「相同来源」刷新时丢失检测结果与显示状态
- 横屏下动效样式与行同步填充不生效
- 韩语轮换模式默认值不在允许值里
- 词条聚合与字符形式投影在中文歌词上错位

## 已知限制

- 桥接的存在性探测中「未安装」分支只有单元测试覆盖；真机上的绑定与提供者交换需要安装 HyperGlow 配套应用才能验证
- 日语、韩语、俄语 README 的本地化仍有历史缺口，非本次引入

## 升级说明

- 从 1.5 直接覆盖安装即可
- 设置、备份与密钥存储格式未变，正常情况下不需要清除数据
- 版本号 1.6.0 / versionCode 12

## 如果升级后出现异常，先清一次本地存储

从旧版升上来后，如果遇到**来源面板显示不对、某首歌一直"检查中"、明明有歌词却显示找不到、来源列表和实际不符**这类现象，通常是旧版留下的本地状态和新版本对不上，清一次就恢复了，不用重装、不用重新登录。按下面的顺序试，从影响最小的开始：

1. **清本模块的歌词缓存**：设置 → 歌词来源 → 「清除已保存的歌词」。只清本模块存的候选与状态，不动 Spotify 自己的数据，不会退出登录。
2. **清 Spotify 的缓存**：系统设置 → 应用 → Spotify → 存储 → **清除缓存**。不会退出登录，不会删下载。
3. **清 Spotify 的存储**：同上位置 → **清除存储**。会退出登录、删掉已下载的歌，是最后手段。

第 1 步通常就够了；三步都试过仍不正常，再当作新问题反馈（带上诊断日志）。
