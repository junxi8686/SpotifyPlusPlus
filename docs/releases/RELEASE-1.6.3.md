# Spotify++ 1.6.3

本版修两处与「逐字歌词」直接相关的问题，并把上一版没做完的翻译面板收尾。

## 变更

- **逐字歌词不再「整句一起变大」**：以前只要开着 Apple Music 动效风格，整行（包括逐字行）都会被套上同一个缩放，看着就是整句一起放大。现在**有真实逐字时间的行不再套整行缩放**，交给逐字上浮、按住的那个字放大这套机制来表现。整行歌词（没有逐字时间的那种）行为**完全不变**。
- **字变白（卡拉OK推进）跟上唱到的字**：以前逐字歌词的白条推进用的是「整行进度」，所以总是慢半拍、落后于实际唱到的位置。现在带真实逐字时间的行改由逐字进度推进，白条会贴着正在唱的字走；整行歌词仍然按整行时间推进（它是按整行时间估的，本来就没有逐字信息）。
- **翻译字号**：显示从错误的 `+0.1s` 改成百分比，并且从「− / ＋」按钮改成**拖动滑杆**（40%–100%，默认 62%），位置在 设置 → 翻译 → 翻译亮度 下面。
- **翻译字重跟随主歌词**：主歌词粗它就粗，主歌词常规它就常规，不再自己定一套。
- **当前句的翻译保持灰色**：主歌词高亮时翻译不跟着变亮，和 Apple Music 一致。
- **顶部模糊调轻**：模糊带从头到尾覆盖的比例从 0.58 收到 0.42，最大模糊半径 14dp 收到 10dp，观感更接近 Apple Music 那种"只有紧贴头部的那行明显虚"。

## 关于「仿 Apple Music 上浮」

它需要把「动画样式」选成 **Apple Music**（默认是渐变扫过，官方默认也一样）。四个开关——载入升起 / Apple 式滑动 / Apple 上浮 / 淡出已唱过的行——都在，开关状态也正确；本版修的是逐字行走到正确渲染路径这件事。

## 已知限制

- 整行歌词（来源没有逐字时间轴时）无法逐字跳动，这是数据本身的限制，不是渲染问题。想要逐字效果请让来源提供逐字歌词（AMLL、QQ 这类）。
- 桥接的存在性探测中「未安装」分支只有单元测试覆盖；真机需要安装 HyperGlow 配套应用才能验证。
- 日语、韩语、俄语 README 的本地化仍有历史缺口，非本次引入。
