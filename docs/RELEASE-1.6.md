# Spotify++ 1.6

本版在 v1.5 的基础上移植了上游 v2.1.0 与 v2.1.4 两个版本的内容，并保留本仓自己的排序、评分与推送策略。

## 新增

- 纸艺着色器背景：纸粒、网格渐变、Kawarp、Voronoi、Perlin 噪声，可单独调参，并跟随封面取色
- 逐字 / 逐词时间轴的字间填充与渐变更平滑
- 语言偏好（优先原文 / 优先中文翻译）
- 手动令牌歌词来源
- Android Auto 显示改进
- 日语注音新增 eza 式拼音 / 粤拼输出
- 悬浮窗与沉浸式界面若干显示修复

## 修复

- 「相同来源」刷新时丢失检测结果与显示状态
- 横屏下动效样式与行同步填充不生效
- 韩语轮换模式默认值不在允许值里
- 词条聚合与字符形式投影在中文歌词上错位

## 已知限制

- 桥接的存在性探测中「未安装」分支只有单元测试覆盖；真机上的绑定与提供者交换需要安装 HyperGlow 配套应用才能验证
- 日语、韩语、俄语 README 的本地化仍有历史缺口，非本次引入

## 升级说明

- 从 1.5 直接覆盖安装即可
- 设置、备份与密钥存储格式未变，不需要清除数据
- 版本号 1.6 / versionCode 9

## 验证

- 单元测试 350 个类 / 2520 个用例 / 0 失败 / 0 错误 / 1 跳过
- 跳过的是 `SettingsCompositionBehaviorTest.schemaMatchesBehaviorInventory`：它依赖本仓不发布的上游文档清单，已显式标注为排除项
- 构建 `:app:assembleDebug` 通过
- 真机（Spotify 9.1.90.2270 / SM-S9280）尚待侧载验证
